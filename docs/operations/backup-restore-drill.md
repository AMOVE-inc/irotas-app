# バックアップ復元訓練

## 方針

本番DB・本番画像を直接上書きせず、隔離した検証環境へ復元する。バックアップの中身や個人情報をGit、Notion、チャットへ添付しない。記録するのは日時、暗号化済み保管先、集計件数、合否だけとする。

## 実施前

1. NonがSites管理画面からD1バックアップとR2バックアップを取得する。
2. バックアップはアクセス制限された暗号化保管先へ保存する。
3. 本番のスキーマバージョン、主要テーブル件数、R2件数・容量だけを、個人情報を含まないマニフェストへ記録する。
4. `pnpm backup:verify <manifest.json>` でマニフェストを検証する。

マニフェストにメール、氏名、住所、Discord ID、Square ID、トークン、カード情報を含めてはいけない。

## 非破壊ドライラン

1. 本番とは別の一時D1・R2を作成する。本番バインディングは変更しない。
2. 一時D1へバックアップを復元する。
3. 一時R2へ画像を復元する。
4. 次を照合する。
   - スキーマバージョンが本番と一致する。
   - 必須13テーブルが存在する。
   - 各テーブル件数がマニフェストと一致する。
   - R2の件数・総容量が一致する。
   - 会員1件、イベント1件、掲示板1件、チャット1件、画像1件を管理者だけで参照できる。
   - 一般会員では管理・非公開データを参照できない。
5. 復元時間、照合結果、差分件数をNotionへ記録する。実データは記録しない。
6. 合格後、一時環境を削除する。削除日時を記録する。

## 合格条件

- 必須テーブル、スキーマ、D1件数、R2件数・容量の差分が0件。
- 画像を含む代表データが表示できる。
- 管理者・一般会員の権限境界が維持される。
- 復元手順と所要時間を第三者が再現できる。
- 一時環境が削除済み。

1項目でも不合格なら、最終移行と全体公開を停止する。
