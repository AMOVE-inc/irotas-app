# 既存会員への登録・移行案内

## 目的

DiscordからIRO+アプリへ移行する既存会員が、Square決済時のメールアドレスを使って安全に初回登録できるよう、案内文・送信順・問い合わせ対応を統一する。

- 配信責任者: Non
- 案内・問い合わせ対応: 運営メンバー
- 技術確認・公開: Codex
- 登録URL: [IRO+アプリ 初回パスワード設定](https://irotas-app-20260721.k1998915n.chatgpt.site/register)
- 通常ログインURL: [IRO+アプリ ログイン](https://irotas-app-20260721.k1998915n.chatgpt.site/login)

## 送信前チェック

1. 本番ヘルス、メール送信ドメイン、認証コード送信を確認する。
2. 最新のSquare会員突合を実行し、説明できない重複・未紐付けを解消する。
3. 運営メンバー、部長、一般会員のテストアカウントで初回登録と再ログインを確認する。
4. 問い合わせ担当、受付時間、障害時の一時停止判断を決める。
5. 一斉送信前に少人数へ先行案内し、登録完了率と問い合わせ内容を確認する。

メールアドレス一覧や認証コードをNotion、Discord、LINE、スプレッドシートの共有画面へ貼らない。

## よくある質問

### どのメールアドレスを使いますか

Squareで会費を決済しているメールアドレスを使用する。別のメールアドレスでは会員資格を確認できない場合がある。

### 認証コードが届きません

迷惑メール、プロモーション、受信拒否設定を確認する。入力したメールアドレスに誤りがないことを確認し、再送は連続で押さず1分以上待つ。10分を過ぎたコードは使用しない。

### 決済メールアドレスが分かりません

本人確認のため公式LINEへ連絡する。公開チャットへメールアドレスを投稿しない。

### Squareを解約・一時停止しています

解約・一時停止中は原則ログインできない。期限超過は7日間の猶予後に停止される。運営メンバー・部長など管理者が設定した免除対象はサブスクなしでログインできる。

### スマートフォンアプリですか

初期公開はスマートフォンのブラウザで利用し、ホーム画面へ追加できるWeb/PWA版。iOS・Androidのストア版は内部テストと審査後に案内する。

### Discordの履歴は引き継がれますか

会員情報、ロール、部活動、対象の掲示板・コメント・画像・イベント履歴を段階的に移行する。移行対象外や確認中の情報がある場合は個別に案内する。

## 配信手順

1. 運営・部長の少人数へ先行送信する。
2. 一般会員のテストグループへ送信し、24時間確認する。
3. 問題がなければ既存会員へ一斉送信する。
4. 未登録者へだけ3日後・7日後に再案内する。
5. 退会済み、ログイン停止対象、既に登録済みの会員へ重複送信しない。

## 配信後の確認

- 認証コード送信失敗、初回登録失敗、ログイン失敗の件数。
- 登録完了数と未登録数。個人のメールアドレスは集計画面へ表示しない。
- 同一内容の問い合わせをFAQへ反映する。
- P0/P1障害が発生した場合は一斉送信を止め、運用・障害報告・問い合わせ対応手順に切り替える。
- 配信日、対象グループ、送信件数、完了件数、問い合わせ件数だけをNotionへ記録する。

## 完了条件

- 正式案内文をNonが承認している。
- 先行グループの初回登録・再ログインが合格している。
- 対象会員へ送信し、未登録者への再案内日を決めている。
- 問い合わせ窓口と障害時の停止判断が運営内で共有されている。
