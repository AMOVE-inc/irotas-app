# 個人情報・決済・権限 最終レビュー

## 目的と判定範囲

本番公開前に、会員の個人情報、Square連携、権限境界が設計どおり保護されているかを確認する。秘密値・メールアドレス・Discord ID・Square識別子そのものは、この文書やNotionへ記録しない。

- 実施責任者: Non（管理者）
- 技術検証: Codex
- 対象環境: Sites本番、D1、R2、Square、Resend、Google連携
- 現在の判定: 技術検証合格。実アカウントの最終受入と本番移行件数の突合が完了するまで暫定NoGo

## 技術検証済み

| 領域 | 合格条件 | 証跡 |
| --- | --- | --- |
| 認証 | 未ログイン利用者が会員・管理APIへアクセスできない | API回帰テスト、本番401スモークテスト |
| 権限 | 管理者、運営メンバー、部長、一般会員の操作範囲をサーバーで検証する | 権限・チャット・部活動・イベントの回帰テスト |
| 決済 | カード番号、CVV、決済トークン、支払額をアプリDBへ保存・表示しない | Square同期実装、依存・秘密情報監査 |
| Square | 会員判定に必要な顧客・サブスク状態だけを取得し、署名済みWebhookを検証する | Square同期・Webhookテスト |
| 個人情報 | 会員一覧・プロフィールは許可された公開項目だけを返す | 会員検索・プロフィール・非公開メモテスト |
| データ移行 | 管理者だけが確定操作でき、件数・実行ID・結果を監査記録する | 会員移行API・ドライランテスト |
| 会員突合 | 未紐付け・重複は集計値だけを管理者へ表示する | v168会員突合レポート、未ログイン401 |
| ログ | URLクエリ、本文、パスワード、トークン、メールを保存しない | 監査ログ・エラー監視テスト |
| 秘密情報 | APIキーをクライアント・Git・Notionへ保存しない | Secretsローテーション手順、Git追跡監査 |
| 保存 | 会員データはD1、画像はR2、端末保存は下書き等に限定する | 共有DB/R2回帰テスト |

## 管理者が本番で確認する項目

人による確認は個別に依頼せず、次の一式をまとめて実施する。

1. 管理者で「概要」を開き、会員突合レポートの件数が元CSVと一致する。
2. 一般会員で管理画面URLを直接開いても閲覧できない。
3. 運営メンバーで管理者限定の会員突合、秘密情報、権限変更を閲覧できない。
4. 部長で担当部活動の申請だけを処理でき、他部活動や管理者画面を操作できない。
5. 解約・一時停止・期限超過7日後の会員がログインできず、猶予期間中の会員は設計どおり扱われる。
6. 管理者と一般会員でログアウト後に保護画面へ戻れず、再ログインできる。
7. Square、Resend、Googleの管理画面に不要な管理者・古いキーが残っていない。

## 移行直前の停止条件

次のいずれかが1件でもあれば本番最終移行を開始しない。

- 会員突合レポートに説明できない重複・未紐付けがある。
- 一般会員または運営メンバーが管理者限定情報を閲覧できる。
- カード情報・認証コード・秘密値が画面、ログ、Git、Notionに残る。
- バックアップ取得と復旧手順の確認が完了していない。
- 最終CSVの更新凍結日時と移行責任者が決まっていない。

## 完了記録

Notionの「テスト結果・受入確認ログ」へ、実施日時、対象権限、端末、合否、確認者だけを記録する。個人情報や秘密値は記録しない。全項目合格後、WBS No.77を完了へ変更し、Go / NoGo判定へ進む。
