# Web/PWA版 段階公開手順

## 公開前の自動確認（Codex）

1. 型チェック、全自動テスト、公開ビルドを完了する。
2. 本番スモークテスト11項目をすべて合格させる。
3. Workerエラーが0件であることを確認する。
4. `/manifest.webmanifest` と `/sw.js` が200で配信されることを確認する。
5. Service Workerが会員ページ、API、チャット、掲示板、投稿画像をキャッシュしないことを確認する。

## 段階公開

1. 管理者アカウントでログイン、ログアウト、再ログインを確認する。
2. 運営メンバー1名と一般メンバー1名で、ログインと主要機能を確認する。
3. 既存会員へ登録URL、初回パスワード設定、ホーム画面追加手順を一括案内する。
4. 公開後24時間は、認証、Square同期、イベント、掲示板、チャットのエラーを重点監視する。
5. 問い合わせは公式LINEと相談・通報窓口へ集約し、個別DMで個人情報を受け取らない。

## 即時停止条件

- 一般メンバーが管理画面または他人の非公開データを閲覧できる。
- 決済情報、メールアドレス、認証情報が画面・ログ・通知に露出する。
- Square停止・解約済み会員がログインできる。
- 誤ったアカウントのプロフィールが表示される。
- データの消失または広範囲な重複登録が発生する。

停止条件に該当した場合は新規案内を止め、Web/PWAをメンテナンス案内へ切り替え、復旧後に対象アカウントで再テストする。

## 完了条件

- 対象会員が本番環境へログインできる。
- iPhone SafariとAndroid Chromeからホーム画面へ追加できる。
- イベント、掲示板、チャット、マイページの主要動線を利用できる。
- 24時間の重点監視でCritical障害が0件。
